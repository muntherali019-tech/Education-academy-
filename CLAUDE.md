# CLAUDE.md

Guidance for AI assistants working in this repository.

## Current state

This repository is currently a **placeholder**. It contains only `README.md` and
no application code, build tooling, or configuration yet.

Per the README, the intended product is **Education Academy** — a cat-themed
learning game for UK learners (Mochi the ginger cat) covering Key Stage 1–3 and
Higher Education, with 15-question puzzle rounds, AI homework photo-marking, a
scan-and-solve helper, a subscription paywall, and a parent/teacher dashboard.

> The actual, buildable implementation of that product lives in the sibling
> repository **`Higher-education-`** (Vite + React front-end, Express backend,
> Capacitor Android build). If you are asked to work on the app itself, that is
> almost certainly the repo to use. Treat this repository as empty until code is
> added here.

## Working here

- There is nothing to build, run, or test yet — no `package.json`, no scripts.
- If you scaffold the project here, keep this file updated: document the stack,
  the commands to install/run/build/test, the directory layout, and the key
  conventions, so the next assistant has an accurate map.
- Until then, do not assume any framework, language, or structure that isn't
  present in the working tree — verify with the actual files first.
